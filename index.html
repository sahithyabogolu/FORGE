METHODOLOGY

Source & calculation notes

SOURCE

Financial information is extracted from the document uploaded by the user. FORGE does not invent missing financial values.

CALCULATED METRICS

Where a metric is not directly reported, FORGE derives it from identified financial statement values using the methodology displayed in the application.

UNCERTAINTY

If FORGE cannot identify the required inputs with sufficient confidence, the metric is shown as unavailable rather than being fabricated.
